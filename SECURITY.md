# Security & save integrity

Please do not put private saves, browser profiles, credentials, or exploit details in public issues.

If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise contact the repository owner through an available private channel before sharing sensitive details. This document does not imply that private reporting has already been enabled.

For an ordinary compatibility bug, include the game build, manager version, browser, the failed action, and a redacted error message. Stop repeating save-affecting actions after a validation error. Keep both the current save and your last known-good backup.

Mods run inside the game page and can have the page's privileges. The current file installer accepts validated declarative loot-rule JSON, not arbitrary executable plugins. Checksums detect changed downloads; they do not make an untrusted publisher trustworthy.
