# Mods

| Feature | Implementation |
| --- | --- |
| [Loot Guard](loot-guard/README.md) | Declarative package plus item-rule, label, filter, and alert runtime |
| [Characters](characters/README.md) | Native archived-hero management and chooser |
| [Gear Loadouts](gear-loadouts/README.md) | Equipment presets backed by the Characters transaction owner |

Characters and Gear Loadouts are built-in source integrations. Loot-rule JSON is the currently supported installable package format. [Submit a contribution →](../CONTRIBUTING.md)
