# Mods

| Feature | Implementation |
| --- | --- |
| [Loot Guard](loot-guard/README.md) | Declarative package plus item-rule, label, filter, and alert runtime |
| [Characters](characters/README.md) | Native archived-hero management and chooser |
| [Gear Loadouts](gear-loadouts/README.md) | Equipment presets backed by the Characters transaction owner |
| [Terrorized](terrorized/README.md) | Same-tier replay and optional post-boss drop gathering |
| [QoL](qol/README.md) | Native charm placement and shared unread control badges |

Characters, Gear Loadouts, Terrorized and QoL are built-in source integrations. Loot-rule JSON is the currently supported installable package format. [Submit a contribution →](../CONTRIBUTING.md)
