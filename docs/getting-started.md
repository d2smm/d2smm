# Getting started

Visit [d2s.arken.gg](https://d2s.arken.gg/), drag the large button to your bookmarks bar, open [D2 Survivors](https://d2survivors.lol/play/), then click the **D2SMM** bookmark. Clicking the button on the installer site displays the drag guide; it cannot silently create a bookmark.

Press **M** to open or close Mod Manager. The shortcut is ignored while typing in text fields or using modified shortcuts. The **MODS** entry in the game menu opens the same panel.

## The gem

During gameplay the gem covers the bottom-center mini-panel button. Click it to open the manager; hover for important notices.

- **Blue:** Loot Guard is off.
- **Purple:** Loot Guard is on.
- **White glow:** an important notice is unresolved.

**More options → Show gem button** hides it and restores the original mini-panel control. M still works on title and character screens.

## Updates

Use **Check for updates**. Update the manager before updating an installed mod. During play, **Save and Exit to update** uses the game's native exit and any confirmation it requires. Cancelling keeps the current manager. At the title screen, the button updates directly.

The manager verifies downloaded bytes before activation. Edited loot rules are not silently replaced; an official rule update is a separate explicit action.

## Storage

Mods and settings are stored in this browser profile on the game origin. Another profile or computer has its own installation. Clearing the site's browser data removes that installation. Export JSON to keep your edited rules.

The bookmark must be clicked again on a new game page. The optional [unpacked extension](../extension/README.md) starts the same manager automatically; it uses the same settings store.

Export a game backup before opting into Characters or Gear Loadouts. A rules export is not a game-save backup.
