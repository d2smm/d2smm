# UI assets

`ui/panel.webp` and `ui/button.webp` are compact AI-generated dark stone/metal UI textures. `ui/gem-on.webp` and `ui/gem-off.webp` are 150×150 variants edited from a user-supplied classic Battle.net-style reference; they are displayed at 66×66 in a 70×70 control. See [rights notes](../NOTICE.md) before reusing derivative artwork.

`fonts/cinzel.ttf` is distributed with its [OFL license](fonts/font-license.txt). Website-only cathedral and gallery assets live in [`site/assets`](../site/assets/). No game sound file is included.

The original independent README banner has separate [generation provenance](../docs/assets/README.md).
